## Описание проекта

Программа представляет собой интерактивное графическое приложение для визуализации двоичных чисел, разработанное на языке Python с использованием библиотеки tkinter.

Пользователь может изменять состояние восьми двоичных регистров с помощью мыши. После каждого изменения программа автоматически вычисляет и отображает десятичное значение полученного двоичного числа.

Цель работы — освоение графических примитивов, обработки событий мыши и реализации интерактивного пользовательского интерфейса.

## Функциональные возможности

### Основной функционал

- Отображение восьми двоичных регистров.
- Переключение значений регистров между 0 и 1.
- Управление регистрами с помощью мыши.
- Автоматический перевод двоичного числа в десятичную систему счисления.
- Обновление результата после каждого изменения.
- Отображение десятичного значения в отдельной области окна.

### Дополнительный функционал

- Отображение значения 0 или 1 внутри каждого регистра.
- Цветовое выделение активных двоичных разрядов.
- Интерактивное обновление графических элементов.

## Требования к системе

Для запуска программы необходимы:

- **Python:** версия 3.10 или выше.
- **Операционная система:** Windows, macOS или Linux.
- **Графическая библиотека:** tkinter.
- **Система контроля версий:** Git.

Программа не требует установки сторонних Python-библиотек.

Библиотека tkinter входит в стандартную библиотеку Python, однако в некоторых установках Python может потребоваться её отдельная установка.

## Установка и запуск

### 1. Клонирование репозитория

Откройте терминал и выполните:

```bash
git clone https://github.com/lxskx/PPPLab1.git
cd PPPLab1
```

### 2. Создание виртуального окружения

Если виртуальное окружение отсутствует или несовместимо с вашей операционной системой, создайте его заново.

Для macOS и Linux:

```bash
python3 -m venv venv
```

Для Windows:

```bash
python -m venv venv
```

### 3. Активация виртуального окружения

Для macOS и Linux:

```bash
source venv/bin/activate
```

Для Windows:

```bat
venv\Scripts\activate
```

### 4. Проверка зависимостей

Для проверки доступности tkinter выполните:

```bash
python -m tkinter
```

Если открылось тестовое окно, библиотека работает корректно.

Дополнительные Python-пакеты для выполнения лабораторной работы не требуются.

### 5. Запуск программы

Выполните:

```bash
python main.py
```

После запуска откроется графическое окно с восемью двоичными регистрами и областью отображения десятичного числа.

## Управление программой

Управление осуществляется с помощью мыши.

Каждый круг представляет один двоичный разряд.

- Белый круг с цифрой 0 означает выключенный разряд.
- Чёрный круг с цифрой 1 означает включённый разряд.
- Нажатие левой кнопкой мыши переключает состояние выбранного регистра.

После каждого переключения программа автоматически пересчитывает десятичное значение двоичного числа.

Нажатие клавиши Enter для подтверждения изменений не требуется.

## Пример использования

### Начальное состояние

После запуска все регистры выключены:

```text
0 0 0 0 0 0 0 0
```

Десятичное значение:

```text
0
```

### Переключение регистров

Пользователь нажимает на первый, третий, шестой и восьмой регистры.

Получается двоичное число:

```text
1 0 1 0 0 1 0 1
```

Программа автоматически вычисляет:

```text
128 + 32 + 4 + 1 = 165
```

Результат:

```text
165
```

### Все регистры включены

```text
1 1 1 1 1 1 1 1
```

Десятичное значение:

```text
255
```

### Все регистры выключены

```text
0 0 0 0 0 0 0 0
```

Десятичное значение:

```text
0
```

## Алгоритм работы программы

1. Создаётся главное окно приложения с использованием tkinter.
2. Создаётся графическая область Canvas.
3. Формируется список из восьми двоичных разрядов.
4. Для каждого разряда создаётся графический круг и текстовое значение.
5. Для элементов регистров назначаются обработчики событий мыши.
6. При нажатии на регистр его значение изменяется с 0 на 1 или наоборот.
7. Программа проходит по всем двоичным разрядам и вычисляет десятичное значение.
8. Полученный результат отображается в графическом интерфейсе.

Для преобразования используется формула:

```text
value = value * 2 + bit
```

где:

- `value` — текущее десятичное значение;
- `bit` — очередной двоичный разряд.
